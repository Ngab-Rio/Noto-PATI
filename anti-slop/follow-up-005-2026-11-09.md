# Tindak Lanjut Audit Antislop: Dukungan Laporan

Temuan yang disetujui: **#1 · R-26**

## Perbaikan

Aksi dukung pada kartu dan detail laporan kini tersimpan melalui Server Action dan RPC database. Guest diarahkan ke login dengan alamat laporan sebagai tujuan kembali; pendaftaran tetap tersedia dari formulir login. Database hanya mengizinkan akun Warga mendukung laporan milik warga lain, satu kali per akun, dengan primary key sebagai pencegah duplikasi. Tabel pendukung tidak dapat dibaca langsung; RPC ringkasan hanya menampilkan jumlah serta status dukungan pengguna saat ini.

Jumlah dukungan kini berasal dari database pada daftar/detail publik, Laporan Saya, dan dashboard Admin. UI menampilkan status memuat, berhasil, sudah didukung, tidak berhak, serta pesan kegagalan yang dapat dicoba ulang.
