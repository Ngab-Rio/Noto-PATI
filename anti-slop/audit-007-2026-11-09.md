# Audit Antislop: Verifikasi Dukungan Laporan Setelah Migrasi

Tanggal: 9 November 2026  
Ruang lingkup: fitur dukungan laporan setelah migrasi Supabase diterapkan.

## Temuan

1. **HIGH · R-35 — Halaman laporan publik gagal dirender untuk guest yang belum login.** Pada `/reports/list`, `supabase.auth.getUser()` mengembalikan `AuthSessionMissingError` saat tidak ada sesi; `getPublicReports` memperlakukan kondisi normal guest itu sebagai kegagalan dan melempar error. Laporan terbaru dan halaman detail juga memakai pemeriksaan sesi serupa, sehingga pengunjung tidak dapat membaca atau mendukung laporan. Pertahankan error sesi yang sungguh-sungguh, tetapi perlakukan ketiadaan sesi sebagai guest.

## Verifikasi

- `npx supabase@latest db push --dry-run --remote` — menyatakan database remote up to date; tidak ada migrasi yang dijalankan selama audit.
- Membuka ulang `/reports/list` pada browser tanpa login menampilkan halaman “Terjadi Kesalahan”; log server/browser berisi `AuthSessionMissingError: Auth session missing!`.
- Detail laporan melakukan pola `getUser()` dan penanganan error yang sama.
- Tidak ada dukungan uji yang dikirim dan tidak ada penulisan ke database.

## Tindak lanjut

Temuan #1 diperbaiki dengan memperlakukan hanya `AuthSessionMissingError` sebagai sesi guest pada daftar laporan publik, halaman detail, dan server action dukungan. Error autentikasi lainnya tetap dicatat dan ditangani sebagai kegagalan.

- `npm run typecheck` — lulus.
- `npx eslint src/lib/auth/session.ts src/lib/reports/public.ts 'src/app/(public)/reports/[id]/page.tsx' src/features/reports/actions.ts src/features/reports/actions.test.ts` — lulus.
- `npm test` — lulus, 20 file dan 154 tes.
- Browser tanpa login: `/reports`, `/reports/list`, dan halaman detail laporan berhasil dirender; kontrol guest tetap menampilkan ajakan untuk masuk guna mendukung.
- `git diff --check` — lulus.
