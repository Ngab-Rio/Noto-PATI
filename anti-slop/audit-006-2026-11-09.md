# Audit Antislop: Fitur Dukungan Laporan

Tanggal: 9 November 2026  
Ruang lingkup: autentikasi, pencatatan dukungan, ringkasan hitungan, dan tampilan laporan.

## Temuan

1. **HIGH · R-26 — Fitur dukungan belum tersedia pada proyek Supabase yang sedang terhubung.** Pemeriksaan `supabase db push --remote --dry-run` masih melaporkan `20261109100000_add_report_supports.sql` sebagai migrasi tertunda, dan halaman `/reports/list` gagal karena RPC `get_report_support_summaries` tidak ada di schema cache. Pastikan migrasi diterapkan pada proyek yang benar dan schema cache siap sebelum warga menggunakan halaman laporan.

## Pemeriksaan

- Server Action memverifikasi sesi dan memanggil RPC yang menerima `auth.uid()` sebagai identitas dukungan.
- UI guest diarahkan ke login; UI warga menonaktifkan dukungan pada laporan sendiri atau laporan yang sudah didukung.
- Unit test action dan tombol dukungan sebelumnya lulus: 8 tes.
- Halaman daftar laporan dibuka setelah permintaan audit; server mengembalikan error RPC `PGRST202`.
- `supabase db push --remote --dry-run` hanya membaca status migrasi dan menunjukkan dua migrasi tertunda: `20261106120000_create_care_education_schema.sql` serta `20261109100000_add_report_supports.sql`. Tidak ada migrasi yang dijalankan.
- Proyek tertaut dikenali CLI sebagai `production`; tidak dilakukan operasi tulis.
